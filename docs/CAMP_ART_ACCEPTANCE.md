# 看山有伴营地视觉验收

本轮改动进入现有原生 Electron 应用的营地页面。从透明桌宠菜单或角色打开营地。可运行工程内的 `Launch-Kanshan.command` 或 `release/看山有伴.app`。

## 场景与素材

- `src/GardenPanel.tsx` 重新摆放洞口、小屋、种子箱、信箱和照料道具。长椅位于田地左侧，刘看山站在椅旁。两处分别可点击，沿用原有聊天入口和角色素材。
- `src/camp.css` 管理独立取景、点击区、奶油色标签、木质标题牌、雪花开关、田格标记与照料效果。土块、植物、田号、反馈和选择轮廓分别渲染。设置、收藏、收起与拖拽走既有入口。
- `src/Plant.tsx` 以已有收藏 ID 稳定映射植物外观。田位、阶段、水分、养分、种子数量和手账关联继续从存档读取。外观选择不需要新增存档字段。开花是已有成长阶段的名称，植物精灵的花、叶或果实为视觉细节。
- `src/assets/camp/` 新增独立透明素材。长椅使用 `bench.png`，土畦使用 `soil.png`。植物包括 `sunflower.png`、`tulip.png`、`bluebell.png`、`lavender.png`、`strawberry.png`、`lettuce.png`、`carrot.png` 和 `sprout.png`。这十张为本轮新绘素材。
- `path-stone.png` 从现有地形素材提取，`cave.png`、`cabin.png`、`seed.png`、`mail.png`、`water.png`、`fertilizer.png` 从现有道具图集提取。工程保留完整背景、原图集和成年角色资源。
- `tests/desktop-camp-art.integration.mjs` 增加真实原生应用的命中、配色、种植和截图验证。`tests/desktop-woodland.integration.mjs` 与 `tests/desktop-home.integration.mjs` 调整原有测试入口与窗口定位。

## 实机截图

截图位置为 `artifacts/camp-art/`。Mac 上运行本轮 Electron 构建，按逻辑像素导出。主截图为 900×740，常用窗口截图为 900×659，另有长椅局部、B2 浇水和 C3 确认播种。截图使用隔离的验收存档，植物组合按此存档的真实数据渲染。

## 回退

本轮保留点在工程下的 `backups/camp-art-20261119/`。

1. 从桌宠菜单退出。先把现有 `release/看山有伴.app` 移到其他位置保留，再将备份里的 `release/看山有伴.app` 放回工程的 `release/` 后打开。
2. 如需回退源码，在工程根目录从 `backups/camp-art-20261119/source.tar` 恢复 `src/GardenPanel.tsx`、`src/Plant.tsx`、`src/camp.css`、`tests/desktop-woodland.integration.mjs` 和 `tests/desktop-home.integration.mjs`。将本轮新建的 `src/assets/camp/` 和 `tests/desktop-camp-art.integration.mjs` 移出源码即可。若这些文件后来有了新改动，先另存再恢复。无需恢复本轮没有改动的 `src/main.tsx`。
3. 新旧应用沿用同一存档结构，正常回退时继续保留用户数据和位置设置。
