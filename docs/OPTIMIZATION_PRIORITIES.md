# 下一步优化 v0.7.1

工期为熟悉工程的一人粗估，服务及美术费用另计。观察和待验证项分开。

| 优先级 | 问题与依据 | 影响 | 建议 | 大致成本 |
|---|---|---|---|---|
| P0 | 已观察：北极狐10条结果混有同名品牌和汽车 | 核心发现不够相关 | 保留原始诊断；让用户确认探索方向，加入有依据的主题重排/歧义提示；不硬删仅缺字面词的结果 | 1天+检索调用 |
| P0 | 已观察：Access Secret误填旧字段，模型provider丢失 | 配置后仍不能用 | 增加主进程安全保存的分服务配置表单、脱敏检查与明确目的地 | 半天—1天 |
| P1 | 已观察：真实协议样本通过；22场景/44调用未跑 | 无法证明长期自然度和人格一致性 | 原规范和原创示例基础上跑真实对照、人工盲评；不先训练 | 半天起+模型费用 |
| P1 | 已观察：只有API摘要；点击原文没有可靠浏览器落地证据 | 无法当全文解读或保证页面可访问 | 保持取得范围标签，补实际原文打开验收；不绕登录和访问限制 | 半天 |
| P1 | 已观察：临时SVG/CSS，多个事件共享动作 | 伙伴表现较单一 | 优先补成年刘看山的观察、思考、落地和照料正式动作包 | 2—5天+美术 |
| P1 | 待验证：原生网络取消、隐藏恢复与快速边界穿透未本轮重测 | 迟到显示和误点击风险仍需桌面证据 | 在有限额度下做实际取消/重试，多屏/缩放/Spaces和长拖动验收 | 1—2天+设备 |
| P1 | 已观察：本地6分15秒开花，10/20小时照料补充节奏 | 可能成长过快、长时照料单调，尚无用户研究 | 小范围试玩后改参数；不加惩罚性枯死或每日任务 | 访谈半天+调整半天 |
| P1 | 已观察：布局仅会话保存、对话仅最近6轮内存 | 重新摆放麻烦，用户可能误判记忆 | 坐标落盘并再校验边界；清楚展示记忆范围，再评估显式可删记忆 | 1—2天 |
| P1 | 已观察：短屏面板较长、完整键盘/读屏未验收 | 阅读和辅助使用存在不确定性 | 测焦点、Esc层级和朗读顺序；内容换行与滚动，保留字号 | 半天—1天 |
| P1 | 已观察：仅本机开发签名 | 团队分发启动未全面验证 | Developer ID签名公证，并在另一台Mac验收 | 1天起+开发者账户 |
| P2 | 已观察：尚无多人后端/共同记忆协议 | 不能称在线社交成品 | 核心稳定后另立范围设计，本轮不擅自扩展 | 另行估算 |

本轮修复配置字段与直答明确任务协议，真实搜索/额度/出题/聊天已通过。没有把这些样本称为语言模型训练，也没有把所有结果当强相关。
