# v0.8.0 · 原生桌宠营地验收

香港时间 2026 年 11 月 18 日。在 Apple Silicon Mac、macOS 26.6.2 的图形桌面上启动实际打包的 `看山有伴.app`。应用为本机 ad-hoc 签名，`codesign --verify --deep --strict` 通过。

| 实测项目 | 结果 |
| --- | --- |
| 默认小窗 | 520 × 330，置顶，只有成年刘看山和原道具；原生 Electron 截屏角落 Alpha 为 0 |
| 展开 | 点击桌面上的刘看山进入营地；同一个原生窗加载随包内置的背景和道具；展开允许缩放并使用普通窗口层级 |
| 三种尺寸 | 900 × 740、720 × 620、600 × 620 的主要道具和九块田中心可命中；截图用实际应用窗口生成 |
| 来源与收藏 | 通过现有 IPC 检索入口，使用注入索引夹具核对来源校验和重复收藏。输入需要逐次授权。此次未发送真实服务请求 |
| 花园 | 从种子箱选种、取消预览、确认、选工具点田、空田反馈、施肥及手账返回均已点过。复验中旧开花植物占 A1，新种使用 A2 |
| 返回和重启 | 收回后恢复小窗、原位置和置顶，再次展开采用同一次运行中上一次营地尺寸。隔离配置重启保留旧收藏、旧田位和新植物，v1 文件逐字节一致 |

67 项 Node 检查通过，签名与内置依赖检查通过。采集的截图及机器记录位于 `artifacts/`。系统拒绝测试进程发送全局指针事件，本版验收覆盖原生窗口状态、透明像素和 Electron 内部命中，尚未复测对后方应用的实际点击与滚轮。多屏及不同缩放未实测。

## 集成与恢复

UI 使用 React 场景和随包 PNG，沿用 Electron 主进程窗口、经过校验的 IPC、成年角色绘制、行为控制器和正式花园存储。旧评审原型继续作为设计记录。窗口切换和操作均不依赖浏览器、服务器或原型的 localStorage。schema 3 未迁移，已开展的植物成长规则继续使用原版本规则。

旧版本源码与签名应用的分发 SHA-256 在修改前重新核对。开发在独立副本完成。本机个人配置和花园文件另以私有临时恢复点保护，验证时使用隔离目录。可从本轮 Mac ZIP 重新解压运行，应用沿用现有本机数据路径。
