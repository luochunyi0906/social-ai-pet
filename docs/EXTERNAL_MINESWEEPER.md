# 外部扫雷陪玩

适配本机 `/Applications/Minesweeper.app`，Bundle ID 为 `com.morecats.Minesweeper`，实测版本 3.0.0（构建 10）。自动陪玩默认开启，设置在「模型与检索设置 → 扫雷陪玩」。

打开真实游戏后，桌宠读取目标窗口的两次稳定画面，显示棋盘尺寸和观察状态。旁边的面板提供「给点线索」「讲详细一点」「告诉我下一步」。淡蓝格表示线索数字，浅黄格表示相关未知区域，三级提示再标一格可证明的结论。「这次先不用」记到游戏进程退出，「关闭自动陪玩」保存在窗口偏好里。

切走或最小化会停止观察并清理提示。回来后重新检查窗口和棋盘。锁屏、休眠、桌宠暂停或隐藏也暂停观察。默认定位验证失败时可框选一次完整棋盘，保存的是相对窗口的矩形坐标。系统权限不足时，可从设置打开 macOS 屏幕录制权限页面。

## 实现

| 文件 | 职责 |
| --- | --- |
| `desktop/native/mines-window.m` | AppKit 进程事件、身份核对、前台与可见窗口信息、ScreenCaptureKit 单窗口采集 |
| `desktop/minesweeper-target.json` | 本机目标身份与适配版本 |
| `desktop/mines-board.cjs` | 规则窗口边距、网格周期和格面特征。低可信格标记为未知 |
| `desktop/mines-companion.cjs` | 单会话、两帧确认、暂停/恢复、旧结果取消、校准与角色反馈 |
| `desktop/mines-hints.cjs` | 仅依据可见数字的相邻约束和集合差提示。用户旗帜属于判断 |
| `desktop/mines-window-placement.cjs`、`desktop/roaming.cjs` | 工作区外侧停靠点与已有桌宠动作调度 |
| `src/MinesCompanion.tsx` | 独立陪玩卡、三级提示、设置和必要时的人工校准 |

屏幕录制授权只用于识别绑定窗口。图像在内存中解析。模型解释需点「授权并问聊天服务」，只调用现有聊天配置传送本地依据文字和本次问题。模型选解释语气，格子与结论由程序给出。基础识别和提示使用本地代码。

识别适用于该版本完整可见的经典棋盘。主题变化、被裁掉的滚动棋盘和低可信符号可能触发等待或人工框选。桌宠只报告能由画面确认的状态。可见结算特征不足时继续保守处理。

复验命令为 `npm test`。扫雷专项覆盖已知线索、误插旗、不确定格、三档解释、偏好持久化和负坐标停靠。原生实测覆盖两种启动顺序、9×9 棋盘自动识别、翻格和插旗、三档提示、切走暂停、返回复读、最小化、主动跳过当次及关闭设置。分发目录的「互动验收」含实机截图和剪辑录屏。

回滚时退出桌宠，从本轮备份的应用 ZIP 解压回 `release/看山有伴.app`。用同目录里的源码 ZIP 恢复对应开发文件，保留当前用户数据目录和本地开发依赖。
