# 知乎来源接入与当前边界

此前主进程使用实验性公共Bing RSS或可配置Brave Search Web API；当时没有知乎官方API凭据，不绕过登录、验证码和访问限制。检索只发确认关键词和站点限制。Bing最多同关键词两地区请求、25秒时限、1MB响应上限；Brave须本机密钥，本轮未验证。

规范化知乎问题、回答和文章HTTPS链接，过滤伪域名、去重，对完整受限响应先筛选再取8条。标题全匹配与部分匹配分开，部分匹配需用户主动显示；标题匹配不等于正文观点相关。index_only只表示实际取得标题、URL、类型、服务与时间，不表示读过正文。
