## 实测结果

使用 Apple Silicon Mac 的实际签名应用，单块显示器。70 项 Node 检查及 19 项原生应用回归通过。全部屏幕尺寸均为窗口逻辑像素。

- 桌宠原生坐标从 `(1222, 715)` 移至 `(38, 243)`，宽高维持 270 × 174，松开未展开。另使用未替换的 macOS 指针采样测试到 `(1411, 238)`，角色可在屏幕右缘抓取。
- 原生截图确认透明角 Alpha 为 0。使用 AppKit 的鼠标按下命中查询和真实原生下层窗口，透明空白命中下层窗口，角色鼻尖命中桌宠窗口。系统未授予进程全局鼠标点击注入权限，完整物理鼠标点击由人工另验。拖动使用应用内按下和松开测试，并另行验证真实 macOS 指针移动驱动原生窗口。
- 展开后可以在飘雪开启和关闭时从标题牌移动整个原生窗口。在同一窗口短时采样各 25 个帧间隔，平均分别约 16.67 ms 和 16.65 ms。该数据用于本机对照，没有覆盖长时间运行或低配硬件。
- 900 × 740、720 × 620、600 × 620 的主要道具及九块田均可见、可命中。已在飘雪开启时复验输入、拖选正文、滚动、确认播种、浇水、施肥、发送消息。检索和对话网络响应使用隔离夹具，没有向外部服务发送测试内容。
- 山洞历史回放、打开来源条目、重复收藏去重、种子箱、取消预览、确认播种、饱和拒绝和手账返回原田位均通过。重启保存雪选项、两态位置、原花园收藏和种植。历史回放保存的是标题和来源，未保留可逐字核验的摘要。实时检索保留原有摘要与覆盖范围呈现。
- 模拟屏幕断开后的无效坐标，应用重启后把两种窗口位置恢复到当前工作区。实机跨屏、实际插拔及不同缩放的多屏组合尚待验证。

原生截图与机器记录位于 `artifacts/`。演示短片采用真实应用帧和原生窗口坐标合成，使用中性底色保护桌面内容。显示器坐标采用 Electron DIP，可查 Electron `screen` 文档。鼠标路由查询使用 AppKit 的 `NSWindow.windowNumber(at:belowWindowWithWindowNumber:)`，采用系统鼠标按下命中规则。

## 启动与回退

在 Apple Silicon Mac 解压 v0.9.0 并双击「看山有伴.app」，可从 `release/` 直接打开已构建的应用。开发时在 v0.9.0 工程执行 `npm ci`、`npm run package:mac`。打包不包含用户数据或密钥。

回退时从菜单退出 v0.9.0，再解压 `rollback/v0_8_0/kanshan_macos_v0_8_0.zip` 并启动旧应用。两版沿用同一个花园数据目录及 schema 3，旧版会忽略独立的 `window-preferences.json`。继续使用最新的个人配置和收藏。v0.8.0 的安装包和源码 ZIP 已在修改前按原 SHA-256 核验，保留为单一回退点。
