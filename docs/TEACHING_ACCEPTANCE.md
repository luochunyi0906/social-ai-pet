# 反向拜师

## 实际操作

- 在营地点击刘看山进入聊天，选择「教看山」。可以选一条收藏、选择当前会话里的用户发言，或输入一个主题。
- 从「收藏手账」打开具体收藏也可以点「讲给看山听」。有接口摘要的收藏显示摘要范围，只有标题和链接的条目会标明正文未查阅。
- 刘看山会先问一个问题。可以在本机保留和整理原话，也可为本轮说明和必要材料授权已配置的模型。最多两次追问，可以提前选「先记到这里」，也可以结束。
- 「改一下」可编辑主题、理解、适用范围、例子、疑点、记录性质和关键词。点「记进手账」并看到确认提示后，学习卡才进入长期检索。知识解释仍会标为待核实。
- 「收藏手账 → 你教给我的」可看卡片、原始解释和来源，返回原会话或收藏，编辑、停用、重新启用或删除。删除学习卡也删除卡内解释副本。原有聊天和收藏按自己的存储规则保留。
- 日后相关聊天会查询有效学习卡。回复实际归因并引用卡片时，可点「用到了你教过的方法」查阅。已修改、停用或删除的原有引用会显示相应状态。

## 文件与数据

| 位置 | 变更 |
| --- | --- |
| `desktop/teaching.cjs` | 单主题任务、候选格式校验、最多两次追问、保存事务、跨会话检索和版本管理 |
| `desktop/chat-session.cjs`、`desktop/chat-model.cjs` | 引入最多两张相关卡片、校验当前版本和引用标记、停止受编辑影响的请求。含教学上下文的回合保留在聊天记录，后续由手账重新检索 |
| `desktop/main.cjs`、`desktop/preload.cjs`、`src/types.ts` | 受信任窗口的 IPC、收藏和原会话来源解析、共享前端类型 |
| `desktop/companion-chat.cjs`、`src/CompanionInvitation.tsx` | 复用冷却和每日额度。教学邀请仅在普通空闲模式出现，拒绝后沿用原冷却 |
| `src/TeachingPanel.tsx`、`src/teaching.css`、`src/ChatPanel.tsx`、`src/GardenPanel.tsx`、`src/main.tsx` | 教学对话、学习卡、手账分类、返回来源和引用入口，复用现有角色调度 |
| `tests/teaching.test.mjs`、`tests/desktop-teaching.integration.mjs` | 持久化、隔离、引用、撤回和原生重启验收 |

个人档案新增 `teaching-v1.json`。外层包括 schema 版本、本机档案标识和记录列表。每条记录保存稳定 ID、版本、确认为有效的时间、更新时间、状态、原会话 ID、学习卡、来源、带消息 ID 的教学答问。删除留下不含卡片与原文的最小关联记录，避免重复保存和旧引用失联。学习卡和正常聊天检索读取同一份记录，关键词按当前有效版本匹配。草稿仅存在当前教学任务中。旧 `chat-v1.json` 仍兼容，可选的教学引用仅记录 ID 和版本。

发送给所选模型的是当前请求所授权的内容和必要的命中卡片字段。原教学全文、记录的用户标识和本机路径留在本地。界面把用户确认保存和事实核实分开。教学文字不会获得文件、窗口或工具权限。

## 验收

- 111 项单元测试通过，其中 5 项覆盖教学记忆、相关检索、来源标记、失败后重试、撤回及主动冷却。
- 原生应用隔离档案通过三种入口、600 × 540 小窗的教学输入、编辑学习卡、保存、重启、新会话调用、打开对应学习卡、停用和删除。此组使用本地固定测试响应，用于核对实际提交给模型的上下文和界面行为。
- 本机 Qwen 3.5 9B 真实推理通过。应用首次用用户示例生成草稿，选择记录性质并确认。完全退出并重启后，在新会话中问迎新招募的衡量方式。回复明确归因于此前的分享，在招募目标下以有效报名数为核心指标，并提供真实卡片入口。截图和测试回执见工作区 `artifacts/teaching`。
- 知乎直答的既有请求链路保留。自动审批未允许将示例会话和学习卡发送到该外部服务，本轮未验证真实知乎直答结果。

可使用 `node tests/desktop-teaching.integration.mjs` 复测原生夹具。已有本机 Qwen 安装时加 `KANSHAN_TEACHING_LIVE=local` 可复测真实推理。

## 回退

修改前做了临时恢复点。目录权限为 0700，个人聊天与主动聊天设置副本仅供本机恢复。恢复点的位置随本轮交付说明提供。

1. 正常退出正在运行的桌宠。
2. 从恢复点将 `workspace.tar.gz` 解压到独立临时目录，以此还原更新前的源码和当时未打包的工作区文件。上一轮 `kanshan_macos_v0_9_9.zip` 与原校验值同放在恢复点里，解压后可替换运行 app。
3. 旧版可直接使用原有个人档案。只有在聊天文件实际损坏或用户明确要撤回之后新增的聊天时，才备份当前文件后选择性恢复 `profile/` 中的旧副本。另行保留 `teaching-v1.json`，可以在重新安装支持教学的版本后继续使用。
4. 验收后按工作区规则清理替代版本及临时副本，当前 v0.9.9 分发包继续作为恢复点。
