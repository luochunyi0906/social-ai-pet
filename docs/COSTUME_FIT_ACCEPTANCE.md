# 桌宠穿搭尺寸与动作验收

原版、狐狸 Q 版与人版分别以各自默认装为基准。站姿按原比例配准可见高度、脚底线和两脚中心。走路、跑步和攀爬按同一形态的默认动作校准。整条动作使用同一组参数，保留抬脚和蹬腿的位移。换装淡出时，上一件服装使用自己的尺寸与位置。

服装定位数据位于 `src/costume-registration.json`，图层共用 `src/CostumeRegistration.ts`。Fox 图集按整条步态统计中位高度与底线。人版身体与局部关节一起对齐。透明活动窗口的留边定义在 `desktop/pet-layout.json`，原生坐标与渲染共用该配置。另接入服装审核中修好的 7 份透明边缘素材。

## 验收

- 在签名 macOS 应用中，用隔离用户目录检查三种形态的 17 组外貌和穿搭。实际打开 AppKit 窗口，走到窗口边缘，攀爬、停靠，再切换到第二个真实窗口。动作阶段与服装资源均在应用里检查。
- 从桌宠拖离营地，验证近距离走回、超过半屏跑回。动作抽帧共 153 张。在 2× Retina 捕获中，可见轮廓与透明窗口边缘最少相隔 18 个设备像素。
- 站姿按 alpha ≥ 96 的实色可见轮廓测量。相对同形态默认装，最高点到脚底的高度与脚底线各相差至多 1 个设备像素，脚掌中点的横向偏差至多 0.5 个设备像素。
- 用衣柜实际试穿与确认，验证原版森林引路者、Q 版六套衣柜服装和人版四套天气服装的持久化。三种形态的雨装与天气触发使用固定观测输入。
- `npm test` 通过 128 项。静态构建和 macOS 本地签名校验通过。实测覆盖当前这台 Retina Mac 的窗口场景。

交付目录 `互动验收` 中的服装尺寸对照图使用原生应用截图，另附站姿和动作像素测量表。可设置 `KANSHAN_TEST_FORM`、`KANSHAN_TEST_OUTFIT` 和 `KANSHAN_MAC_SDK`，运行 `node tests/desktop-dressed-window.integration.mjs` 复验。可设 `KANSHAN_FOX_PROOF` 为存在的目录以保存抽帧。

本轮沿用 v0.9.9 及原用户数据目录。恢复到已交付构建时可退出应用并从对应的 macOS 分发包重新解压。源码包和校验值与应用同批交付。
