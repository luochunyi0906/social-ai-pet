# 看山有伴 v0.9.3 小屋开发预览

## 使用

双击解压后的「看山有伴.app」，或在源码目录运行 `./Launch-Kanshan.command`。点击桌面角色进入营地，再点暖木小屋的「回家」。收藏手账仍由营地里独立的手账道具打开。

- 点击床上的「休息／睡眠」入睡。灯光变暗，床上出现共用被窝。点「起床」或桌面上的「休息中 · 叫醒」可以唤醒。macOS 的「看山有伴」菜单 →「操作菜单」也保留「叫醒刘看山」。
- 点击衣柜，柜门打开后进入换装。选中套装只改变预览，点「穿上」才确认。关闭预览保留上次确认的装扮。「恢复默认装扮」直接切回白色刘看山。
- 睡眠是应用内的会话状态。可以在睡着时确认换装，唤醒后穿着该套装。每次重启从清醒状态开始，恢复最后确认的套装。唤醒恢复原来的正常、暂停或低打扰选择。全程不操作 macOS 睡眠。
- 入睡后停止自主行为时钟、飘雪和装扮的特殊动作，用户主动使用衣柜和花园时仍可得到操作反馈。无连续陪伴要求或惩罚，当前版本不播放音频。晨间纸条和夜间小故事留待后续。

## 本地数据与回退

增量工程独立保存在 `previews/kanshan-p0-v0_9_3`。上一版 `previews/kanshan-p0-v0_9_2` 的源码、签名应用和两个分发包均保留原位置。修改前签名复验通过，两个包的 SHA-256 与该目录的 `delivery/SHA256.json` 一致。

预览沿用 `~/Library/Application Support/看山有伴-林间预览`。套装 ID 在独立的 `outfit-preference.json` 中原子写入，和窗口位置及花园数据分开。已有 `garden-v1/v2/v3.json`、`model.env`、窗口偏好继续使用原路径。回退时退出 v0.9.3，运行 v0.9.2 的 `Launch-Kanshan.command`。旧预览会忽略 v0.9.3 的装扮文件，保留其中的偏好供再次升级恢复。正式版 v0.9.0 与开发预览使用不同数据目录。

## 首个服装包

- 两份上传的 INFJ ZIP 核对为同一内容，SHA-256 为 `df7aa6776e8b2c3b7362b161a2481b47aba99d199c68c56904ddbc54187bd174`。原 README 随资产保存在 `src/assets/outfits/forest-guide/README.md`。
- 一个 ZIP 对应「森林引路者」一张套装卡。32 张素材为 320 × 320 的 8 位 RGBA PNG，身体、衣服和法杖都在同一画面。衣柜动图沿用 ZIP 的 GIF，运行时由 PNG 清单控制播放。
- [首套配置](../desktop/outfits/forest-guide.json) 使用固定画布。README 的脚底 y=315 保留，实测双脚横向中心约 x=160。统一缩放 1.54，映射到成年基准的共同锚点 (120, 296)。所有帧共用同一画布和锚点，透明像素和特效保留。
- 水晶提示按 `001…032`、20 FPS、单次 1.6 秒调度，结束回到本套 `001` 待机帧。GIF 带独立的循环元信息，运行时不使用它。源 PNG 中有完全相同的帧，打包后可共享同一文件，播放仍按 32 帧位置读取。
- 触发点是靠近花园、找到探索结果、衣柜内主动展示或清醒时确认穿上。睡眠、暂停和低打扰抑制特殊动作。拖动照常更新原生窗口坐标，本套缺少行走和睡眠素材。行走时保持本套待机图，睡眠使用共用被窝，睡醒恢复已确认装扮。

## 新增服装 ZIP

1. 每个 ZIP 对应一个唯一套装 ID，建议使用小写字母、数字和连字符。素材包含同画布透明 PNG 序列、PNG 或 GIF 预览、README。所有 PNG 使用一致的画布和角色脚底基线，特效留在透明区域内。
2. 将帧和预览登记到 `src/assets/outfits/<id>/`，在 `desktop/outfits/<id>.json` 提供名称、说明、素材类型 `full-character`、画布、锚点、统一比例、可点击角色轮廓和预览文件。默认 ID `default` 保留给内置角色。
3. `actions.idle` 必填，其余按实际素材登记。动作提供有序文件名、FPS、`once`／`hold`／`repeat` 和结束落点。完成睡姿素材后登记 `actions.sleep`，即可替换共用被窝。未具备的动作在 `unsupported` 中说明。
4. 当前通过工程登记并重新构建来接入素材。执行 `npm ci`、`npm run package:mac`、`npm test`。有 GUI 的苹果芯片 Mac 可运行 `npm run test:desktop`。预览或换装遇到无效清单、损坏图片或不兼容画布会显示提示，当前生效的套装与存档仍保留。

## 验收范围

在 macOS 原生 Electron 开发包中复测小屋、家居独立点击、休眠中断与唤醒、预览取消、素材损坏后重试、确认与默认装扮、本地持久化、桌面热区、拖动储存位置、原收藏手账及小窗口。详细自动验收记录在 `artifacts/home/home-acceptance.json`。用测试档案和合成故障验证隔离，没有外发个人收藏或依赖联网模型。记录采用实际原生窗口截图和演示，实体副屏及其他架构未验收。

构建与 73 项自动测试通过。新增的 6 组原生验收和原营地的 22 组回归均通过。录像为签名应用测试窗口的实际操作，字幕与指针圆环用于标注步骤。睡眠姿态以共用被窝呈现，森林引路者行走和睡姿尚待正式素材。
