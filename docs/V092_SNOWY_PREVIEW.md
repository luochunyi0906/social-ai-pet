# 看山有伴 v0.9.2 覆雪林间开发预览

根据评审原图还原常驻入口。应用在 270 × 174 逻辑像素的透明窗中运行。覆雪地台、暖灯石洞、右后花箱、右前信箱、三块全名圆木牌和右上角菜单均按参考图比例定位。

## 构图与素材

- `src/assets/snowy/cave.png`、`garden.png`、`mailbox.png` 是以参考图为源按轮廓独立导出的透明素材。对应热区由 `src/snowy-art.tsx` 的轮廓控制。
- `src/assets/snowy/terrain.png` 是根据参考图单独制作的透明覆雪地台，包含积雪、松枝、石块和暖光路径。通过透明窗显示当前系统桌面。
- `src/Fox.tsx` 是原成年刘看山资产，文件与 v0.9.0 逐字节一致。原图的静止立体材质与现有动态角色有可见差异，常驻显示层只调整了色温和接地阴影。
- `src/DesktopPet.tsx`、`src/desktop-pet.css` 和 `src/shared/layout.mjs` 组织图层、完整中文名称、状态反馈和碰撞。木牌使用可维护文本，松枝、地台、阴影及雪花不捕获输入。
- 小雪花与已有飘雪开关共用偏好。隐藏、暂停或低打扰时停用常驻雪花，系统减少动态时保留静态雪花。
- 原图为本轮上传的「image(20261118-134846).png」。应用包内使用独立资产，查阅原图可见：<https://chatgpt.com/library?file_id=libfile_474302a2f6bc819194fa740d6eaabc82&account_id=personal>。

## 运行与回退

- 在苹果芯片 Mac 上解压应用包并双击「看山有伴.app」。从源码目录可运行 `./Launch-Kanshan.command`。
- 源码使用 Node 24。运行 `npm ci` 后执行 `npm run package:mac`，输出为 `release/看山有伴.app`。在 macOS 图形会话可运行 `npm run test:desktop` 复验。
- 预览沿用独立的 `~/Library/Application Support/看山有伴-林间预览`。用 `Configure-Model.command` 编辑预览配置。线上配置与密钥留在本机。
- 正式 v0.9.0 的应用包、源码和数据保存原位。需要回退时，从预览更多菜单退出，再打开原应用。旧应用包和源码包的哈希位于原项目 `deliveries/v0_9_0/SHA256.json`。

## 原生测试和截图

- 在 Apple Silicon、macOS 26.6.2 和 Electron 45.3.3 上用签名应用验证。浅色、深色、照片三类壁纸均有默认和悬停实拍，六宫格按逻辑像素显示。实拍在真实桌宠后放置独立壁纸测试窗口。
- 单元测试验证布局与碰撞、索引来源、收藏兼容及种植等。原生流程覆盖小窗拖动和松手、道具入口及菜单、AppKit 鼠标命中、主窗口拖动、收起和重新展开、飘雪、搜藏种植、手账及重启恢复。
- 在线搜索和模型使用测试响应。素材和窗口不依赖在线服务。真实跨副屏和系统级物理鼠标点击未录制，原生穿透通过 AppKit 命中查询核验。
- 原始 macOS 截图、压缩包哈希和机器可读测试记录随交付提供。
