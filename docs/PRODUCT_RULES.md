# 当前产品规则 v0.7

最新用户指令优先于旧提案的阶段限制。当前实现：透明桌宠、主动文字/TXT/PDF投喂、知乎接口来源/摘要、可选旧索引、主动收藏、用户手动种植、有限本地互动、可选模型对话。好友、跨设备、社交、复杂经营不在本轮。

新收藏先成为种子，不占空田。用户从种子箱选中一颗已有种子后，可选择固定九种植物之一并主动点击播种，植物关联该收藏并种在第一块空田；没有可用种子时不显示品种选择。相同品种允许重复种植。采摘成熟植物后释放田位、保留收藏并点亮植物图册。播种、浇水、施肥和采摘均由用户主动发起，模型与自主行为没有提交这些操作的权限。成长为本地时间规则，不是模型成长或人格训练。

默认角色沿用原版，玩家可改用人版或狐狸版立绘，原版可继续使用衣柜装扮。单行为控制器统一暂停、低打扰、拖动、业务事件及自主动作。

狐狸版在普通桌面模式下 2 分钟未互动会发呆，默认装扮的眼皮缓慢垂下。点击桌宠或指针移入角色时睁眼并重新计时。移动与攀爬期间由对应动作优先表现。

鼠标接近桌宠时，支持的站立立绘追踪指针，离开附近后视线回正。提起狐狸 Q 版和人版的默认外观时，衣领出现受力褶皱，身体以衣领附近为支点小幅晃动。

狐狸 Q 版、人版和原版在普通桌面模式下都能穿着当前服装沿真实窗口攀爬，靠近合适侧边时可自动触发。右键刘看山仍可手动发起。窗口仍须有安全边缘和顶部空间，暂停、低打扰和拖动期间不自动触发。天气使用手选城市的 Open-Meteo 当前数据。

点击桌面或营地的山洞打开探索桌，再点「山洞入口」播放本地换装间彩蛋。桌宠菜单也可打开探索桌，选择角色外貌。关闭场景、退出播放或隐藏窗口时结束当次访问。

山洞彩蛋播放到人物露面后，首次赠送 9 张 Q 版动图。奖励保存在本机，玩家可从聊天表情的「山洞赠礼」分组手动发送。

投喂在逐次授权后只读正文，选择前不读文件内容；原文件不移动。模型只发必要文本，搜索只发确认关键词。密钥仅主进程读取本机文件，不打包、不回传。没有模型时明确模拟，搜索索引/生成问题/解读分开；未取得正文不概括作者观点。

收藏私密本机保存，无后台浏览、剪贴板监视、音频、截图或联网同步。隐藏主题只隐藏显示，不是存储加密。删除收藏同时清除关联种子/植物，其他资料保留。

schema3兼容旧v1/v2收藏和植物；原收藏字段保留，旧田位植物保留为开花。新快照写garden-v3.json，旧个人文件不覆盖。损坏格式拒写，串行原子提交。

版本保留：完成态仅保留当前源码、应用及对应分发包。处理中临时恢复点验收后清理，原始文档/素材、当前配置、个人收藏继续保留。

当前服务默认知乎搜索/直答，使用本机ZHIHU_ACCESS_SECRET；OpenAI配置保留但非默认。直答只发model/messages/stream，不假设JSON响应参数可用。接口摘要不是全文；仅用户明确同意时向模型发送有界摘要。额度按钮只查当日限免次数，不解释为钱包余额。其他平台能力只研究，不自动接入OAuth、上传文件或读取账户收藏。
