# 待补素材 v0.6

当前成年外形沿用既定矢量骨架，所有动作和植物阶段为临时实现。没有复制其他开源桌宠的角色或人格。

- 成年透明动作：侧看、招呼、悬提、落地、嗅闻、叼纸、阅读、思考、发现/无结果/失败，统一画布与落地点。
- 种植陪伴动作：选种观察、播种点头、浇水观察、施肥观察、发现生长/开花。角色不代替用户种植。
- 植物透明阶段：种子、播种土壤、幼苗、生长、开花；水滴、肥料颗粒。当前已有可玩矢量阶段，但没有正式美术。
- 独立山洞、投喂箱、花园入口与种子箱正式素材，不能整张背景带角色烘焙。

不改变成年五官和身体比例；Fox/Plant组件接口便于替换。不要加入幼年、多季服饰或新角色。正式发布IP与素材授权需团队核对。
