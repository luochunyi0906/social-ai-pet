# 天气、鼠标、山洞衣柜与窗口互动

## 操作

桌面营地右上角使用手选城市的当前气温，四舍五入到整摄氏度。气温独立于自动换装，在「模型与检索设置」可以选城市、立即更新、查看观测时间及服务错误。服务使用所选城市的公开坐标，通过 Electron 原生网络请求 Open-Meteo。打开雪地追逐开关后，可在紧凑桌宠的雪地台上快速来回移动鼠标。

用主键轻点角色可抬头，约 1.5 秒后进入原入口。1.5 秒内连点三次出现抱头泪眼和擦泪。按住角色移动至少 15 个逻辑点进入拖动，蓝白日常装的狐狸 Q 版被拎起时，从后衣领受力的前倾动作过渡到脸朝地的悬空姿势。松手后轻缓落稳，约 15 秒无互动后返回营地。以营地所在屏幕的可用宽度为准，距离超过一半用跑步，较近用走路。

山洞彩蛋里人物露面后开放狐狸 Q 版衣柜和人版天气衣柜。狐狸 Q 版支持 6 套手选，左右拖动、方向键或视角按钮查看一整圈，也可以选择「查看实际效果」。点「确认穿上」保存。手选服装优先。恢复默认后，温和无特殊天气时使用蓝白日常立绘，其余按天气自动换装。人版可在衣柜锁定某套衣服，或恢复随手选城市天气切换。原版衣柜只保留绿色「森林引路者」，手选后可恢复默认与天气换装。低温仅更新气温显示，服装沿用日常或手选。人版旧厚衣存档恢复随天气切换。

三种形态都能穿着当前装扮使用窗口互动。刘看山走到合适窗口侧边约 38 个逻辑点内会自己爬上去。在刘看山身上双指点按或右键点击，选择「去窗口边上玩」，可让他主动走过去。顶部需要留出约一个桌宠的高度。停靠后，切换到另一个应用窗口可触发下落。暂停、低打扰、隐藏、拖动和打开桌宠面板时会停止自动触发。

## 素材清单

| 类别 | 当前内容 |
| --- | --- |
| 山洞衣柜 | 明服、汉服、民国学堂、苗族服饰、藏族服饰、都市冬装大衣。蓝白雨天装随天气触发 |
| 层级素材 | 轻装覆盖、墨镜、泪滴和离身雪屑 |
| 原版狐形窗口 | 看向窗边、接近、手臂抓握和腿蹬、翻上顶部、坐姿晃腿、失衡、离开窗沿、弧线下落、恢复站姿 |
| 狐狸 Q 版默认装扮 | 用户新主图、左右走路与跑步帧、背身攀爬帧、分层晃腿、落地和雪屑、发呆眼皮 |

六套取自本轮「拟人服饰」透明原图，正侧背直接使用原稿，补绘角度组成 8 向转台，动作帧保留每套原衣身和配饰。步态、攀爬及衣柜预览共用这些衣料设计，雨衣与戴帽造型随动作保留。它们可以试穿并保存。原版默认外观沿用三视图，森林引路者使用原稿和补绘方向分层驱动手脚，人版使用对应衣服的正面、侧面和背面分层驱动。狐狸 Q 版默认装扮的走路和抓边帧取自 `up(1).zip`，蓝白日常装的跑步使用 `跑步姿势(1).zip` 中 8 张姿势表原帧，在 `src/assets/cave/motion` 保存为透明 WebP 帧条。帧条移除了原 GIF 的整段屏幕位移，位置仍由同一个桌面控制器推进。上沿翻身复用抓边帧，停靠晃腿使用新主图的分层裁切，落地与抖落雪屑使用轻微姿态变化。狐狸 Q 版的高温轻装使用新版参考图。特定天气保留配套动作，左右走路及跑步各 14 帧，背身攀爬 18 帧。服装按原帧对齐，仅更新衣服区域。上沿翻身延续抓边素材，停靠、下落和拍雪沿用同一套穿搭。墨镜使用和走跑同步的独立帧层，爬行时随背身隐藏。抓握、下落与落地保留同一套戴帽雨衣。狐狸 Q 版的服装在两分钟发呆时使用轻微歪头，默认主图另外有眼皮过渡。人版轻装使用覆盖层。高温轻装的成品在 `src/assets/cave/weather/motion`，由站立参考图、以原攀爬帧为底图补绘的背面穿搭以及原始动作帧合成。

六套手选服装的预览和动作素材位于 `src/assets/cave/outfits-q`。每套转台由 8 张静态视角组成，正、左、背三个方向来自原图，另外五个方向使用原图补绘。详细操作及素材用法见[狐狸 Q 版六套服装](PET_INTERACTIONS.md#狐狸-q-版六套服装)。

## 实测记录

- 本机原生签名包从香港实况读取气温 15.6°C，桌面显示 16°C。用隔离档案注入 20.4°C、0°C 和无法取得读数，确认了晴好换回蓝白日常图、关换装恢复手选、标签穿透和切换城市时不保留上一城市的温度。

- macOS 隔离档案检查锁定的穿戴请求和衣柜、实际彩蛋解锁、一次性提示、6 项、试穿后确认、重启恢复及模拟天气触发对应装扮。
- `node tests/desktop-cave-wardrobe.integration.mjs` 检查实际视频解锁、6 套各 8 个视角、按键及拖动、600 × 560 小窗、试穿取消和重启恢复。
- 本次六套服装逐套在原生 macOS 桌宠和 AppKit 窗口实测近程走、远程跑、拖起、靠窗、攀爬、翻上窗沿、停靠、切窗下落及落地的服装保持。
- `node tests/desktop-daydream.integration.mjs` 以可控时钟检查 2 分钟界限、眼皮中间帧和互动重计时。`node tests/desktop-fox-motion.integration.mjs` 用隔离档案和测试光标坐标核对两种归营步态。狐狸 Q 版另用两个独立 AppKit 窗口验证实际抓边、翻上标题栏、晃腿及切窗后的单次甩落。
- 使用两个隔离的原生 macOS 应用窗口验证窗口采样和整个攀爬链。真实切窗触发一次失衡和甩落。原版及人版落地后直接站立，Q 版保留原来的落地流程。首次候选包出现的浮点坐标崩溃已修复，坐标由统一移动出口取整。切窗时并发的显示器变更通知现在重新校验边界。
- 使用独立 AppKit 浮窗验证靠近侧边自动触发、爬升与停靠，以及切换应用后的单次落地。
- 这轮动作素材在签名应用和隔离档案中检查。注入低温、炎热强日照和冷雨观测，实测近距离走回、远距离跑回及真实 AppKit 窗口的自动攀爬，核对动作帧实际播放和停靠、切窗及走开时的穿搭。低温条件沿用日常或手选服装，陪听也使用日常素材。
- 原生鼠标事件验证单击抬头和原入口、三连点与擦泪、15 点拖动阈值及悬空动作。雪地追逐以固定随机值验证命中分支及离开停止。
- 天气解析、阈值与确认、晃动检测、窗口范围和窗口调度有自动测试。改用 Electron 原生网络后，签名应用在本机读到香港 Open-Meteo 当前数据，样本体感 12.2℃。冷雨组合、切换后恢复手选和随机追逐使用测试输入。炎热、强日照的实况及多屏物理攀爬尚待逐项实测。

原生实录在工程 `artifacts/weather-window`，分别为「真实窗口-攀爬与甩落.mp4」及「山洞-衣柜解锁.mp4」。窗口实录中两块带标题的窗口是独立运行的 AppKit 测试应用。录屏期间用测试底板遮盖其他桌面内容。

## 构建与回滚

运行 `npm test` 和 `npm run package:mac`。编译窗口元数据辅助程序需要 macOS Command Line Tools。当前机器存在较新的 SDK 和较旧的链接器，构建使用 `KANSHAN_MAC_SDK=/Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk`。辅助程序只读取窗口编号、进程、前台和矩形边界。测试录屏使用单独的系统录屏命令。

如需回退，请使用先前的应用包和对应源码包。用户档案继续留在同一目录。

接口依据：[Open-Meteo Forecast API](https://open-meteo.com/en/docs)，[Apple CGWindowListCopyWindowInfo](https://developer.apple.com/documentation/coregraphics/cgwindowlistcopywindowinfo(_:_:))。
