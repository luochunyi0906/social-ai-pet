### 山洞彩蛋与角色外貌

在桌面或营地点击山洞会打开探索桌，再点击「山洞入口」播放换装间视频。播完或点击「离开」回到探索桌。

桌宠菜单的「打开山洞」可直接进入探索桌。选择「人版」或「狐狸版」后，桌面和自由活动中的角色会使用对应外貌，重启会恢复本机偏好。选择「恢复原版与衣柜装扮」可以重新使用已有套装。默认装扮的狐狸 Q 版会走路、跑步和攀爬，桌面上 2 分钟未互动时眼皮会慢慢垂下。

山洞彩蛋解锁后，狐狸版可以在「暖木小屋 → 换装」浏览 6 套服装。左右拖动预览可按 8 个角度转一整圈，也可点「正面／侧面／背面／另一侧」。选择缩略图后可以先查看各角度，再点「确认穿上」保存。

已用签名应用和隔离档案实测两种外貌切换与重启恢复、从紧凑桌面和展开营地进入山洞，再点「山洞入口」播放，以及 Esc 和播完返回。对应命令为 `node tests/desktop-cave-appearance.integration.mjs`。

营地右上角的「收藏手账」在「飘雪」左侧。在营地点击暖木小屋「回家」，用床切换休息。原版衣柜只保留绿色「森林引路者」。左右拖动预览可按 45° 查看八个方向，点「穿上」保存，点「恢复默认装扮」切回原本的外观。桌面睡眠期间可直接点击「休息中 · 叫醒」。[小屋用法与素材规范](docs/V093_HOME_PREVIEW.md)。

苹果芯片 Mac 桌宠。启动 `release/看山有伴.app`，透明置顶的刘看山会出现在桌面角落。单击角色互动，双击进入营地，右上角「收回桌面」或 Esc 恢复悬浮。按住刘看山本体可单独拖动角色，按住雪地或营地拖动手柄可移动整个营地。营地顶部木牌用于移动主窗口，右上角「飘雪」可关闭效果。两种位置和雪花开关会分别保存。

- 在营地点击山洞，或在桌宠菜单选择「打开山洞」，可以在探索桌读取历史回放或检索知乎。请求仍需确认，来源范围随结果显示。
- 点击信箱投喂文字或 TXT、PDF，双击营地里的刘看山或点击长凳聊天。
- 收藏后从种子箱选种，点空田预览，确认后播种。九块田上的品种互不重复，照料或重开应用后品种保留。拿起水壶或肥料，再点击目标田。门边手账可打开原来源或回到已有植物的田位。
- 在刘看山身上双指点按或鼠标右键点击，可打开桌宠菜单。菜单提供聊天、暂停、低打扰、隐藏和退出。展开窗口可缩放，关闭后恢复原桌宠位置。
- 「模型与检索设置」的「桌面自由活动」可选全桌面或营地附近。全桌面模式下，角色离开营地，在可用屏幕区域散步，停留后归位。营地和道具留在原处。默认装扮散步时播放透明底走路 GIF，停留时切回待机。
- 默认装扮的狐狸靠近合适的真实窗口边缘时会自行攀爬。右键菜单里的「去窗口边上玩」可手动发起。天气设置可选城市并读取 Open-Meteo 的当前天气。

开发预览以独立应用身份运行，首次出现在桌面左下角。浏览产生的收藏、种植、窗口位置和设置存入 `~/Library/Application Support/看山有伴-林间预览`。需要测试在线服务时，用此目录的 `Configure-Model.command` 配置预览的 `model.env`。预览沿用既有服务流程与 schema 3 数据兼容逻辑。分发包包括源码所需的配置示例，运行数据与密钥留在本机。

开发使用 Node 24，依次运行 `npm ci`、`npm test`、`npm run package:mac`。有现成应用时打包脚本拒绝覆盖。打包后可在 macOS 图形会话中用 `npm run test:desktop` 独立启动并复验。项目的 `deliveries/v0_9_9` 目录提供当前应用包、源码包和 SHA-256 校验值。

衣柜和散步可用 `node tests/desktop-scarf-wardrobe.integration.mjs` 与 `node tests/desktop-stroll.integration.mjs` 复测。两项通过签名应用的原生窗口检查画面和交互，使用临时用户资料和本地测试响应。衣柜的 112 张视角图和 42 张对应的缩略及备用图复核了透明边缘。青绿休闲套装的正面额头使用原图像素补回，其余视角保留 RGB，只调整透明度。本轮未复测联网服务。单元测试另行覆盖散步出发、停留、返回和手动拖动归位的动画切换。

## 在应用内配置模型

在营地点击齿轮，或在桌宠右键菜单选择「模型与检索设置」。可以设置投喂模型、文字聊天和检索服务，填写兼容 API 地址、模型 ID、访问密钥或知乎 Access Secret。保存后新的请求立即使用这份配置。独立应用使用本机用户目录的 `model.env`，开发模式使用 `.env`。已设置的密钥只显示设置状态，空白密钥输入保留原有值。

## v0.9.9 文字聊天

聊天中的「教看山」可以把用户分享的经验或解释收成可编辑学习卡。确认保存后，相关新会话可检索这条记录。「收藏手账 → 你教给我的」提供来源、编辑、停用和删除入口。[反向拜师操作与验收](docs/TEACHING_ACCEPTANCE.md)。

直接打开 `release/看山有伴.app`，在营地选择「和刘看山聊聊」。默认通过桌宠内置的知乎直答 Skill 使用快速档，填写本机 `model.env` 的 `ZHIHU_ACCESS_SECRET` 可连接。需要用本机 Qwen 时，打开 `Launch-Kanshan-Qwen.command` 或在配置里明确选择 `CHAT_PROVIDER=llama.cpp`。[Skill 安装路径与本轮验收](docs/ZHIDA_SKILL_ACCEPTANCE.md) · [会话策略](docs/ZHIDA_CHAT_ACCEPTANCE.md)。


## 系统闹钟

在小屋的床边桌打开「闹钟」。首次使用时导入「看山有伴·创建系统闹钟」快捷指令。2026 年 11 月 19 日实测通过该快捷指令在 Mac「时钟」中创建并启用了香港时间下午 2:00、名为「看山有伴」的闹钟。该次快捷指令未生成桌宠读取的文本回执，桌宠可能提示未收到确认。此时先在 Mac「时钟」检查，再决定是否重试。闹钟保存在系统中，不随应用包或源码迁移。
